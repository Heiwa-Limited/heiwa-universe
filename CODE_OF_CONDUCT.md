# Code of Conduct

This repository expects direct, respectful collaboration.

## Expected behavior

- Be precise about technical claims.
- Critique code, docs, and assumptions without attacking people.
- Prefer evidence, reproductions, and concrete proposals over status games.
- Respect project boundaries around privacy, provider ownership, and local-first execution.

## Unacceptable behavior

- Harassment, intimidation, or discrimination.
- Deliberate misrepresentation of results, authorship, or system maturity.
- Sharing private credentials, personal data, or sensitive logs without permission.
- Repeatedly derailing work with bad-faith or abusive communication.

## Enforcement

Repository maintainers may edit, remove, or reject contributions and discussions that violate this standard.
