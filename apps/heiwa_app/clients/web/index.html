Why Heiwa exists

Not another hosted router.

Heiwa is for operators who want one runtime across local models, provider CLIs, and API-key providers without handing the runtime, app, memory, or secrets to someone else's hosted surface.

Hosted gateways Centralize traffic

Useful for remote model access, but they are not the same thing as a self-hosted operator runtime.

Heiwa Centralizes operator control

Operator flow

1. Install

Start from a one-line install or GitHub Release. The runtime lands on the operator machine.

2. Connect providers

Authenticate provider CLIs, add keys, and discover local models. Heiwa normalizes the lanes.

3. Run with receipts

Use the REPL, open the local app with heiwa app, and keep evidence on the machine.
