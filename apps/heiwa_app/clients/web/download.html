Install & Releases

Install locally. Run locally. Keep the surface local.

The canonical public path is a one-line installer. Tagged GitHub Releases stay the source of truth for platform archives and checksums. The web surface here only hands you software — it does not run operator work.

Canonical install path curl -fsSL https://heiwa.ltd/install | sh

The installer pulls the appropriate archive for the host and verifies the checksum. The manifest stays authoritative for mirrors and offline verification.

1 · BOOTSTRAP

Run the install path or unpack a tagged release. State lands under ~/.heiwa/.

curl -fsSL https://heiwa.ltd/install | sh
2 · VERIFY

Run heiwa doctor to confirm local runtimes, provider CLIs, and local evidence state.

heiwa doctor
3 · OPEN

Open the local operator surface with heiwa app. The web sits on localhost, never on a hosted dashboard.

heiwa app

03 · Source of Truth

GITHUB · CLOUDFLARE · LOCAL

GitHub Releases remain the source of truth.

The installer is a convenience path. Tagged GitHub Releases are where archives, checksums, release notes, and platform build outputs live. The public site is a shop window — it delivers software, never operator state.
