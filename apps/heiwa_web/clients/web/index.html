Personal AI OS

Your AI. Your rules. One system.

Heiwa is a personal operating system that turns AI tools into a coordinated workforce. One agent orchestrates, four execute, and everything stays sovereign.

Documentation Source Code

One agent, four tools

Heiwa is a single intelligent agent that delegates work to Claude, Codex, Gemini, and Antigravity — picking the right tool for every task based on cost, capability, and context.

Always on, always aware

Running 24/7 on Railway, Heiwa monitors its own health, manages state through SpacetimeDB, and communicates with you through Discord and CLI.

Sovereign by default

Private work stays local. Cloud tools run through official subscriptions, never leaked keys. The system is honest about what it can and can't do.

Architecture

Built to run, not to demo

No wrappers around chatbots. Heiwa classifies intent, scores risk, routes to the cheapest capable model, and executes through a unified tool mesh. Real orchestration, not prompt chains.
