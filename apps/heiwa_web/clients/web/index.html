Canonical Heiwa Stack

CLI, MCP, HTTP API, and docs on one fast control plane.

Heiwa is being consolidated around a narrow runtime/public split: Railway runs the hub, SpacetimeDB is the state direction, Cloudflare serves the public shell, and status moves over WebSocket-first transport with HTTP diagnostics fallback.

Supported surfaces

The public-first, supported Heiwa surfaces are intentionally narrow.

  • CLI for operator workflows
  • MCP for tool interoperability
  • HTTP API for public-safe runtime access
  • Docs for architecture and runbooks

Runtime boundary

The runtime and the public shell are separated on purpose.

  • Railway hosts the hub runtime
  • Cloudflare Pages serves marketing and docs
  • Public status remains read-only

Speed posture

Slow compatibility stories are not the public architecture target.

  • SpacetimeDB for fast synchronized state
  • WebSockets for live status and events
  • No stack-complete legacy chat or portability claims

Public truth

What this site does not claim

This public shell does not present legacy chat ingress, auth gateways, experimental canvases, or placeholder agent personas as complete product surfaces. If a capability is not covered by docs and CI, it is out of scope for this site.
