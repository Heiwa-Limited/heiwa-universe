Personal AI OS

One person's operating system for getting things done with AI.

Heiwa is a distributed system that coordinates AI tools, manages state, and executes tasks — built by Devon for Devon. It's not a product yet. It's a workshop. If you're here, you're looking at the workbench.

Read the Docs View Source

What it does

Routes tasks to the right AI tool. Keeps state in sync. Runs on Railway, stores truth in SpacetimeDB, and talks to you through Discord and CLI.

How it works

A hub process coordinates agents that classify intent, score risk, pick the cheapest capable model, and execute through a unified tool mesh. No single vendor lock-in.

Where it's at

Early and honest. Some parts work well, some are still being wired up. The docs say what's real. If it's not documented, it's not done.

Philosophy

Sovereign by default

Your data stays yours. Private work runs locally. Cloud tools are used through official subscriptions, not leaked API keys. The system is honest about what it can and can't do — no hype, no vaporware.
